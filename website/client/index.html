Seu sistema.
Mais simples.

Instale programas, remova o que não usa e execute tarefas de manutenção em uma interface única para Windows e Linux.

Atualizações automáticasAs releases são verificadas diariamente no GitHub e ficam disponíveis aqui para você escolher a versão certa.

Comece em segundos.

Use o launcher oficial para instalar a versão estável ou testar o canal beta diretamente pelo terminal.

Versão estável

Windows PowerShell
irm https://raw.githubusercontent.com/JLBBARCO/programs-manager/main/core-app/run.ps1 | iex
Linux
curl -fsSL https://raw.githubusercontent.com/JLBBARCO/programs-manager/main/core-app/run.sh | bash

Canal beta

Windows PowerShell
$env:AIP_BRANCH = 'beta'; irm https://raw.githubusercontent.com/JLBBARCO/programs-manager/beta/core-app/run.ps1 | iex
Linux
AIP_BRANCH=beta curl -fsSL https://raw.githubusercontent.com/JLBBARCO/programs-manager/beta/core-app/run.sh | AIP_BRANCH=beta bash
