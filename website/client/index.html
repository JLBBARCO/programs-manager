Programs Manager

Programs Manager is a program developed in Python from easy manager of programs in your computer

Commands

Default Command

Windows PowerShell

Stable
irm https://raw.githubusercontent.com/JLBBARCO/programs-manager/main/core-app/run.ps1 | iex
Beta
$env:AIP_BRANCH = 'beta'; irm https://raw.githubusercontent.com/JLBBARCO/programs-manager/beta/core-app/run.ps1 | iex

Linux

Stable
curl -fsSL https://raw.githubusercontent.com/JLBBARCO/programs-manager/main/core-app/run.sh | bash
Beta
AIP_BRANCH=beta curl -fsSL https://raw.githubusercontent.com/JLBBARCO/programs-manager/beta/core-app/run.sh | AIP_BRANCH=beta bash

Run any version of the program

In the command, if you add the version name in front of the link of the repository, you can run any version of the program.
For example: $env:AIP_VERSION = '3.02.4'; irm https://raw.githubusercontent.com/JLBBARCO/programs-manager/main/core-app/run.ps1 | iex
